# 20 — 茶事百科知识板块（Tea Knowledge Hub）

> Tea Atlas 独立知识板块：六大茶类档案 · 制茶工艺 · 品茶方法 · 存储保鲜
> 文档状态：方案已确认，开发中（用户确认后开工）

---

## 1. 模块定位

「茶事百科」原为茶信录弹窗的第三 Tab（`TeaCatalogPopup` 内），本轮将其**单拎为独立板块**：

- 独立入口：底部控制栏新增「茶事百科」按钮 → 打开独立知识弹窗 `TeaKnowledgeHub`。
- 茶信录内第三 Tab 保留（快捷入口，不重复渲染）。
- 内容从"速查表"升级为**带图详解**：六大茶类档案、制茶工艺全景、品茶方法、存储保鲜四大章节，配真实图片。
- 目的：毕设答辩展示"茶文化深度"——地图（空间维度）→ 详情（单品维度）→ 百科（知识维度）三层闭环。

## 2. 决策记录（已与项目负责人确认）

| 决策点 | 结论 |
|---|---|
| 入口形态 | 底部控制栏新增「茶事百科」按钮，打开**居中大弹窗**（max-w 560px，水墨风），非侧边抽屉（内容量大，居中更适合章节阅读） |
| 与茶信录关系 | ~~茶信录第三 Tab 保留~~ → **已删除**（2026-10-18 用户确认）：茶事百科完全独立，茶信录恢复双 Tab（产地茶/现代茶饮），两处共用同一数据源 `teaKnowledge.js` 的历史约定不再适用，茶信录不再渲染知识内容 |
| 内容结构 | 4 章节：① 六大茶类档案 ② 制茶工艺全景 ③ 品茶方法 ④ 存储保鲜 |
| 配图 | 网上搜索真实茶叶/茶具/工艺图（无水印高清），本地压缩归类到 `images/knowledge/`，来源标注"据公开茶文化资料" |
| 数据源 | 扩展现有 `client/src/data/teaKnowledge.js`（新增 `TEA_CLASS_PROFILES` 详细档案），不新建数据文件 |
| 真实性 | 所有工艺/水温/保质期等知识为通行茶文化常识，统一标注学术用途；不编造具体品牌数据 |

## 3. 数据模型（teaKnowledge.js 扩充）

新增 `TEA_CLASS_PROFILES`（key = categoryEn，7 类），字段：

```js
{
  name: '绿茶',            // 中文类名
  intro: '不发酵茶，杀青定型，保留鲜爽',   // 一句话定义
  craft: ['杀青', '揉捻', '干燥'],        // 工艺链
  represent: ['西湖龙井', '碧螺春', '安吉白茶'], // 代表茶
  taste: '清汤绿叶，鲜爽回甘',             // 口感特点
  teaColor: '绿黄明亮',                   // 汤色
  ware: '玻璃杯 / 白瓷盖碗',              // 推荐茶具
  ratio: '1:50',                          // 茶水比例
  storage: '密封避光、冷藏保存，保质期约 6–12 个月', // 存茶
  image: '/images/knowledge/green.jpg',   // 配图（本轮新增）
}
```

原有 `TEA_CLASS_KNOWLEDGE` / `BREWING_GUIDE` / `CRAFT_OVERVIEW` 保留，茶信录 Tab 继续使用。

## 4. 前端实现

### 4.1 新组件 `client/src/components/Knowledge/TeaKnowledgeHub.jsx`

- 居中大弹窗（`max-w-[560px]`，圆角水墨风，AnimatePresence 入场动画，与全站动效一致）。
- 顶部标题「茶事百科」+ 副标题"六大茶类 · 工艺 · 品鉴 · 存茶" + 关闭按钮。
- 4 个章节区块，纵向滚动：
  1. **六大茶类档案**：7 类卡片（绿/红/乌龙/白/黄/黑/花），每卡配图 + intro + 代表茶 + 口感 + 汤色 + 工艺链。
  2. **制茶工艺全景**：从采摘到干燥的通用步骤图解（图文行）+ 六大茶类工艺差异一览表。
  3. **品茶方法**：水温 / 冲泡时间 / 茶具选择 / 茶水比例 四要素详情卡（配茶具图）。
  4. **存储保鲜**：四大关键因素（避光/防潮/控温/远离异味）+ 各茶类保存方法表。
- 底部统一学术标注："知识依据公开茶文化科普资料整理，图片来源于网络，仅用于毕业设计学术研究，非商业用途。"

### 4.2 入口接线

- `BottomControlBar.jsx`：新增「茶事百科」按钮，props 增加 `onKnowledgeOpen`。
- `MapPage.jsx`：新增 `knowledgeOpen` state，渲染 `TeaKnowledgeHub`，传 `onKnowledgeOpen` 给底部栏。
- `TeaCatalogPopup.jsx`：第三 Tab 不改（复用同一数据源）。
