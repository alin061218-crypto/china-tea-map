# 19 — 现代茶饮模块设计（Modern Tea Beverage Module）

> Tea Atlas 新增模块：传统产地茶 → 现代消费形态 → 品牌化传播
> 文档状态：方案已确认，待开发（用户确认后开工）

---

## 1. 模块定位

本模块在现有"产地原叶茶 + 茶文化"地图之上，增加一条**现代消费延伸线**，形成完整叙事闭环：

```
产地原叶茶（现有地图） → 现代消费形态（瓶装即饮茶 / 新茶饮奶茶） → 品牌化传播（果子熟了 × 杨紫） → 反哺年轻人认识产地茶
```

它不是与产地茶平级的新数据类，而是挂在现有茶叶数据上的**新内容层级**。核心创新点：**茶底溯源**——"这瓶茶的龙井来自浙江""这杯奶茶的茶底来自福建"，用反链把现代饮品拉回产地地图。

## 2. 决策记录（已与项目负责人确认）

| 决策点 | 结论 |
|---|---|
| 现代茶饮视图 marker | **品牌产品独立造点**：每个品牌产品在地图上生成独立点位，点位定位在其主要原料产地城市附近（非纯虚构坐标） |
| 宣传模块形态 | **果子熟了产品宣传卡 + 杨紫元素融入**：宣传果子熟了产品时，把杨紫代言元素作为内容板块融入（代言传播分析） |
| 数据扩展方式 | 在 `demoTeas.js` 每条茶上**追加可选字段**（`modern_forms` / `beverage_chain`），不改表结构、不破坏现有渲染 |
| 挂载范围 | 36 条茶中仅给有真实关联的 8–12 条补字段，其余茶保持无字段（现代视图下自然不显示） |

## 3. 数据模型扩展

### 3.1 字段结构（追加，非必填）

```js
// client/src/data/demoTeas.js 内，某条产地茶对象追加：
{
  // ...原有字段（name/province/city/latitude/longitude/category/... 不变）
  modern_forms: [
    {
      type: '瓶装即饮茶',        // 枚举：瓶装即饮茶 | 奶茶茶底 | 现代调饮
      brand: '果子熟了',
      product: '茉莉龙井',
      note: '茉莉花香窨制 × 龙井绿茶茶底，0糖0脂0能量即饮茶',
      anchor: { province: '浙江', city: '杭州', latitude: 30.20, longitude: 120.35 } // 独立造点坐标（原料产地城市附近）
    }
  ],
  beverage_chain: '浙江杭州西湖 → 龙井绿茶 → 果子熟了·茉莉龙井（即饮茶）'
}
```

- `type` 枚举固定三类，避免脏数据。
- `anchor` 是该产品的独立点位（原料产地城市坐标 ±0.2° 偏移，避免与产地茶 marker 完全重叠）。
- 未挂载 `modern_forms` 的茶：传统视图 / 现代视图均按现状渲染。

### 3.3 数据真实性口径

- 销量、热度、增长等数字一律标注"据品牌官方/媒体报道"，不写死成定论（例：销量数据出处为 36氪报道，北京商报 2025-05-08 转引）。
- 不虚构代言关系、不编造产品不存在的工艺描述。
- 详情见 §6 引用来源清单。

## 4. 前端实现方案

### 4.1 视图切换（MapPage）

- `MapPage` 增加 `viewMode` state：`'traditional' | 'modern'`。
- 底部控制栏（`BottomControlBar`）新增视图切换入口（"传统茶 / 现代茶饮"）。
- 传统视图 = 现状完全不变。
- 现代视图 = 渲染"品牌产品独立点"（由各茶 `modern_forms` 展开生成 products 数组，含 `anchor` 坐标）。

### 4.2 地图 marker（TeaMap）

- `TeaMap` 接收 `viewMode` prop。
- `modern` 视图下：
  - 渲染产品点：图标换为瓶装茶 / 奶茶图标（新增 assets，水墨风格，沿用 `tea-icons` 的绘制语言），气泡色取自原料产地的大气氛围 profile。
  - 点击产品点 → 打开详情，详情内容为"品牌产品 + 茶底溯源"，并保留反链回到对应产地茶。
- 产品点数据源：`demoTeas` 中所有 `modern_forms` 展开（`getModernProducts(teas)` 工具函数），避免另起数据结构。

### 4.3 详情面板溯源区块（TeaDetailPanel）

- 当 `tea.modern_forms` 存在时，面板新增"现代茶饮 / 茶底溯源"区块：
  - 每个 `modern_forms` 条目渲染品牌卡：品牌、产品名、type 徽标、note（工艺与溯源说明）。
  - "原料产地"子区块：反链到对应省份（点击高亮地图省份 / 定位到对应产地茶 marker），实现溯源闭环。
- 无 `modern_forms` 的茶：面板保持现状。

### 4.4 目录弹窗双 Tab（TeaCatalogPopup）

- 顶部增加"产地茶 / 现代茶饮"两个 Tab（不做进分类下拉，避免与 category 字段混淆）。
- "现代茶饮"Tab：汇总所有品牌产品条目（brand × product × 原料产地），点击定位回对应产地茶并打开详情。

### 4.5 宣传区块（果子熟了 × 杨紫）

- 入口：地图内新增"品牌故事"入口按钮（水墨风格，贴合现有视觉）。
- 打开宣传抽屉（复用 `TeaDetailPanel` 的抽屉交互与视觉语言），内容分三块：

**① 品牌案例卡（果子熟了）**
- 品牌定位：花香 × 原叶、无糖健康，做"年轻人喜欢的饮料"（品牌使命，据品牌官网）。
- 产品线：栀栀乌龙、金桂乌龙、茉莉龙井等 10 余种花香 + 茶香口味（据北京商报转引 36氪、电商在售信息）。
- 市场表现：据 36氪报道，2024 年 3 月–2025 年 2 月销量突破 4 亿瓶（标注"据媒体报道"）。
- 包装视觉：东方美学、水墨/花鸟元素（与项目水墨风格呼应）。

**② 代言人传播分析（杨紫元素）**
- 2024-05-06：官宣杨紫为无糖茶系列代言人（据澎湃新闻；彼时正值其主演剧集热播期，品牌以"果子熟了，果和'紫'也熟了"谐音出圈）。
- 2025-05-07：杨紫升任"全球品牌代言人"（据北京商报）。
- 2026-06-01：品牌发布长期倡议"中国花香茶计划"，杨紫以"花神"形象出席，获授"中国花香茶计划联合发起人"（据紫牛新闻、Foodaily）。
- 传播逻辑：大众明星 IP 降低年轻人接触茶文化的门槛 → 花香茶产品成为"第一杯茶" → 带动认识产地原叶茶 → 回到地图溯源。这是"传统茶年轻化传播"课题的落点。

**③ 结论区块（茶文化年轻化）**
- 链路图：明星 IP → 花香茶产品 → 认识产地原叶茶 → 回到地图（与 §1 主线闭环一致）。

**⚠️ 肖像权红线（答辩必看）**
- 宣传区块只放品牌官方宣传物料的小尺寸截图 + 文字描述。
- 页面固定标注："图片来源：果子熟了官方宣传物料，仅用于毕业设计学术研究，非商业用途"。
- **禁止** AI 重绘杨紫人像、禁止用其肖像做产品主视觉、禁止暗示"杨紫推荐本设计"。
- 文档、答辩材料中不写"杨紫推荐我做的茶"，只能分析"品牌 × 代言"这一真实营销事件。

## 7. 风险与合规

- **数据真实性**：营销数字一律标注"据品牌官方/媒体报道"，答辩被问出处可答来源清单。
- **肖像权**：见 §4.5 红线，宣传区块不生成、不重绘代言人形象。
- **视觉一致性**：现代茶饮模块沿用现有墨色、纸张质感、水墨图标语言，禁止跳成科技感卡片。
- **回归安全**：所有改动为追加式（新字段 + 新组件分支 + 新视图），传统视图路径零改动。
